## Summary
Following an architect-mode review, the user decided to migrate Anki-related skills from the main project into the anki-mcp submodule, aiming to decouple them from Diotima-specific concepts like groves and managed models so the skills could eventually be portable under the DAFNE architecture. Four concrete structural decisions were made: strip Spanish-specific coupling out of the skills, move idiom-batch auto-suspend logic to the languages grove (tracked as a separate issue), make the anki-add-cards pipeline invisible to end users (pipeline-only), and resolve a naming collision between a skill and a pipeline. A first session began mapping out how the worker should receive deck names to become grove-blind but was left incomplete, with the exact parameter passing for `add_notes` and the full scope of reference updates still unresolved. A follow-up session executed the relocation: skills were moved into the anki-mcp submodule, Spanish-specific logic was split off into separate issues, and anki-add-cards was made pipeline-only as planned. After committing, the session discovered that part of the pipeline file's content edits had been incompletely staged and fixed this via a git commit amendment. The relocation is now complete, with the submodule and parent repo synchronized locally but not yet pushed, leaving the change ready for testing before publication.
